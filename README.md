# Classroom Interactives

Self-contained classroom interactives for 7th-grade Life Science. No student data.

These pages are meant to be posted in Google Classroom as a Link so they open in a browser tab on Chromebooks and the classroom ViewBoard.

## Live pages

- [Researching and Citing Evidence (Gold King Mine Spill)](https://spoobjw.github.io/classroom-interactives/gold-king/citing-evidence.html)

## Contents

- `gold-king/citing-evidence.html` — practice finding, underlining, quoting, paraphrasing, and citing evidence from a vetted source.
